# 팀 개발 안내

## 실행과 작업 위치

저장소를 복제한 폴더에서 `npm.cmd ci`, `npm.cmd run dev`를 실행합니다. 기본은 모의 데이터입니다. 실제 카메라나 AI 추론을 실행하지 않습니다.

| 기능 | 파일 |
| --- | --- |
| 모니터링·이력·사용 안내 | `src/App.tsx` |
| 상태·이벤트 타입과 병합 | `src/domain/` |
| 모의 시나리오·브라우저 저장 | `src/data/mockSource.ts` |
| 사진·상세 창 | `src/components/` |
| 스타일·모바일 대응 | `src/styles.css` |

확인과 종료를 분리하고, 연결 단절과 입력 미감지를 구분합니다. 사진이 없어도 텍스트 경보와 확인 기능은 유지합니다.
