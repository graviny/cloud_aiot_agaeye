- Unix 초·snake_case 변환, 정상·주의·위험·분석 불가·아기 미감지 구분.
- 생존 신호가 반복되어도 정지한 프레임 시각으로 정상 상태를 새로 만들지 않음.
- 몸 박스 없는 얼굴 가림 결과와 아기 미감지를 구별.
- 실제 API 경로 프록시와 이름 없는 `type: device/event` SSE 수신.
- 다른 장치의 이벤트 제외, 현재 `active_event_id`와 일치하는 사진 선택.
- 사진 URL 로딩. 테스트 이미지는 한 픽셀 PNG이며 실제 카메라 사진 아님.
- 보호자 확인 후 위험 유지, 확인 실패 시 미확인 유지.
- 오래된 재전송으로 이미 받은 확인·종료 시각이 취소되지 않음.
- 연결 단절·복구, 종료 미확인 이력 유지, 미등록 기기의 서버 연결 상태 구분.
- 늦게 도착한 REST 정상 응답이 새 SSE 위험 결과를 덮어쓰지 않음.
- React StrictMode 정리 전의 요청·SSE가 새 연결 세션을 덮어쓰지 않음.
- 연결 모드의 390px 화면에서 가로 넘침 없음.

미등록 기기 검사에서 서버가 살아 있는데 ‘연결 중’으로 보이는 문제가 처음 발견됐고, 상태 객체가 없어도 성공한 서버 연결을 표시하도록 수정한 뒤 3개 검사가 모두 통과했습니다.

학습된 ONNX 가중치, 실제 FastAPI와 모델 출력의 종단 연결, Pi 카메라 단절·성능·인식률·알림 지연은 별도 검증 대상입니다. 서버 메모리 저장의 재시작 손실, 촬영 시각·카메라 자체 진단 미제공, 불완전한 종료 기록, 2차 알림 UI·웹 PUSH 범위는 [모델 연결 안내](MODEL_INTEGRATION.md)에 기록했습니다.
## 제공받은 모델로 노트북 실분석 검증 (2026-10-14)

`aga-eye-model-v1.tar.gz`에는 ONNX(12,651,058바이트), 원본 `.pt`(6,488,618바이트), 결과 CSV가 있었습니다. 허용한 일반 파일만 추출했고 각 SHA-256을 `model-artifacts/MANIFEST.json`에 기록했습니다. ONNX는 실제 실행했으며 `.pt`는 역직렬화하지 않았습니다.

검사는 순서대로 실행했으며 브라우저는 Edge 작업자 1개·GPU 비활성화를 사용했습니다. 모델은 CPU 스레드 2개로 실행했습니다. 위 추론 시간은 특정 프레임·입력에서 관찰한 값이며 평균 성능이나 합격 기준을 의미하지 않습니다.

실제 위험 사진 저장·보호자 확인 흐름은 기존 규격/모의 경보 검사로 확인했습니다. 합성 영상에는 아기가 없으므로 실제 모델의 아기 위험 정확도·누락률 시험은 아닙니다. 제공받은 CSV를 이 노트북에서 재평가하지 않았으며 실제 Pi 성능도 미검증입니다.

`laptop-ai-demo.png`, `laptop-ai-mobile.png`는 합성 영상만 담은 화면입니다. 웹캠의 실제 사용자 화면은 공유 캡처에 넣지 않았습니다. 검증 후 카메라는 중지하고 웹·로컬 서버만 실행 상태로 두었습니다.
