# 화면 구성

- 시작/로그인/가입: 아이디와 비밀번호, 아이 정보 등록
- 홈: 현재 카메라 상태, 수면 시간과 타임라인, 수면 환경 점검 2×2
- 모니터링: 카메라 미리보기와 자세·얼굴·주변 물체·가장자리 관측
- 우리 아이: 프로필과 히스토리
- 히스토리: 날짜별 수면 요약, 수면 기록 추가·수정·삭제
- 아가아이 연결하기: 기기 코드 승인, 기기 목록, 연결 해제
- 설정: 안전 알림과 계정 관리

관측이 오래되거나 입력이 없으면 정상으로 표시하지 않고 확인 불가로 표시합니다.
카메라 안전 알림과 보호자 확인 흐름은 유지합니다. 울음 관련 경로/메뉴/전송 요청은 없습니다.
수면 기록은 서버에 먼저 저장하고 아이별 로컬 캐시를 갱신합니다. 수정 충돌과 권한 검사를 유지합니다.
